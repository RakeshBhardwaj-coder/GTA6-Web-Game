# GTA6 Web Game — By Rakesh Bhardwaj

A 2D coastal getaway car racing & police chase game created by **Rakesh Bhardwaj**, built with **Vite**, **React**, **TypeScript**, **Tailwind CSS**, and a custom **HTML5 Canvas** 60fps simulation engine.

## Features

- **Endless High-Speed Chase**: Race across Sunset Beach Strip, Keys Causeway, and Neon Bay Expressway with escalating 5-star pursuit heat.
- **3 Custom Rides**: Choose between Coral, Teal, and Gold cars with distinct speed, drift grip, nitro, and armor stats.
- **5-Star Pursuit, Power-Ups & Stunts**: Near-miss combo chains, handbrake drift boosts, jump ramps, Health & Boost Potions, rare **20s Beast Armor** invulnerability shields, spike strips, helicopters, and tank roadblocks.
- **Procedural Web Audio**: Synthesized engine purr, tire screech, sirens, near-miss chimes, and crash effects with mute toggle (`M`).
- **Global Leaderboard & Seed Challenges**: Compete on the live leaderboard and challenge friends with deterministic run seeds.

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Production Build (Web / itch.io)

```bash
npm run lint
npm run build
```

Upload the contents inside the generated `dist/` folder as an HTML5 `.zip` package.

## Controls

- `A` / `D` or `Left` / `Right`: Steer (or Touch Swipe / Buttons on mobile)
- `W` / `Up`: Boost Speed
- `Space`: Drift / Handbrake
- `Shift` / `N`: Nitro Boost
- `Esc`: Pause
- `R`: Quick Restart
- `M`: Mute / Unmute Audio
